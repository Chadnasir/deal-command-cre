# Deal Command

https://raw.githack.com/Chadnasir/deal-command-cre/main/index.html

Local: `/workspace/cre-deal-command/index.html` (single-file offline copy)

## Features
- Kanban pipeline (Lead → Closed) with drag-and-drop + localStorage
- Deal drawer (edit SF, rent, NNN, notes, stage)
- Cap rate + cash-on-cash calculator with visible formulas
- Suite inventory filters (max rent, min SF, city)
- Tour brief generator (copy + print)
- CSV export + keyboard shortcuts (`/` search, `N` new deal)

## vs typical Grok Build
1. Broker brand (navy/orange, Instrument Sans + Source Serif) — not Inter/purple AI slop
2. Real persistence and stage workflow, not a static mock
3. Auditable underwriting math
4. CSV + print CSS for actual use
5. Accessibility + shortcuts
6. CRE-shaped sample Southern OC inventory (demo data)
